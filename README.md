# WorkBalance

Plataforma web para la gestión y seguimiento de la carga laboral.

## Descripción

WorkBalance es un proyecto de trabajo de grado orientado a la gestión de tareas y solicitudes de trabajo, con el objetivo de facilitar la visualización y seguimiento de la carga laboral.

## Tecnologías

- Python
- Django
- PostgreSQL
- HTML
- CSS
- JavaScript
